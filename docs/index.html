Security Audit Kit

Toolkit otomatisasi security testing web/API lintas sistem operasi, berbasis konfigurasi — DAST + SCA, non-destruktif dengan rollback otomatis, dan laporan berstandar konsultan IT security.

⭐ GitHub Open scanner (pasif) Contoh laporan

Apa ini

Security Audit Kit mengadaptasi alur pentest berbasis OWASP menjadi automated regression testing yang dapat dijalankan lokal maupun di CI. Satu entry point python audit.py <modul>, identik di Windows dan Linux, dengan kredensial lewat environment variable.

Modul

Access control & BOPLA

Privilege escalation, IDOR, forged header, bypass gateway, mass assignment (destruktif + rollback otomatis).

Injection & upload

SQL injection (error/boolean/time-based) dan penolakan upload berbahaya.

Web stack & CVE

Banner Server/X-Powered-By → CVE (Apache, NGINX, PHP), dependency CVE via Trivy.

CORS, redirect, TLS, header

CORS misconfiguration, open redirect, TLS/cipher usang, security header.

SCA & SAST

CVE dependency (Trivy) + SAST (semgrep) + secret ter-commit (gitleaks).

Laporan

Standar konsultan: executive summary, ID temuan, CVSS indikatif, bukti endpoint & screenshot, varian HTML/Markdown/slide.

Mulai cepat

pip install -r requirements.txt
cp config/targets.example.yml config/targets.yml   # isi base_url target Anda
python audit.py all                                # scan + laporan
