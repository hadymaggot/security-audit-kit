Open Scanner — passive check

Security Audit Kit · by hadymaggot
Non-intrusive. Only reads responses that are already publicly served — security headers, cookie flags, CORS, and the Server/X-Powered-By banner → CVE. It does not send attack payloads, write data, or brute-force (like securityheaders.com / SSL Labs). For in-depth testing, use the CLI on targets you own or are authorized to test.
