Security Audit Kit · dibuat oleh hadymaggot
Non-intrusif. Hanya membaca respons yang sudah dilayani publik — security headers, cookie flags, CORS, dan banner Server/X-Powered-By → CVE. Tidak mengirim payload serangan, menulis data, atau brute-force (seperti securityheaders.com / SSL Labs). Untuk uji mendalam (injection, access control, upload, dll.), gunakan CLI pada target yang Anda miliki/berwenang uji.
